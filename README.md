# افعل على Render

تطبيق عربي خفيف لإدارة المهام المتكررة ومتابعة التنفيذ والإحصائيات. الواجهة تعمل مباشرة من خادم Node، وتحفظ الحسابات والبيانات في PostgreSQL على Render.

## النشر على Render

اربط مستودع GitHub بالخدمة أو استخدم Blueprint الموجود في `render.yaml` عند إنشاء مشروع جديد فقط.

- Build command: `npm ci && npm run build`
- Start command: `npm start`
- Health check: `/health`
- Account API: `/api/account`
- Admin API: `/api/admin`

ينشئ `render.yaml` خدمة الويب وقاعدة PostgreSQL ويربط `DATABASE_URL` تلقائيًا عند استخدام Blueprint. المشروع الحالي لديه خدمة قائمة باسم `EF3L`، لذلك لا تنشئ Blueprint آخر للمستودع نفسه حتى لا تتكرر الخدمة.

قاعدة المشروع الحالية على Render:

- الاسم: `ifal-render-db`
- النوع: PostgreSQL 16
- المنطقة: Frankfurt
- متغير الربط داخل خدمة الويب: `DATABASE_URL`

## متغيرات البيئة

- `DATABASE_URL`: رابط PostgreSQL. يضاف تلقائيًا عند استخدام Blueprint.
- `ADMIN_SET`: أسماء مستخدمي المديرين مفصولة بفاصلة، مثل `tariq,admin2`. المطابقة لا تتأثر بحالة الأحرف.
- `APP_TIME_ZONE`: المنطقة الزمنية المستخدمة للتقارير الشهرية. القيمة الافتراضية في Blueprint هي `Asia/Riyadh`.
- `SESSION_DAYS`: مدة جلسة تسجيل الدخول بالأيام، والقيمة الافتراضية 30.

متغيرات الصيانة الاختيارية:

- `DELETE_ACCOUNT_NOW`: أسماء الحسابات المطلوب حذفها، مفصولة بفاصلة.
- `CHANGE_PASSWORD`: بالشكل `username:new_password`.
- `CHANGE_USERNAME`: بالشكل `old_username:new_username`.
- `CHANGE_NAME`: بالشكل `username:new_name`.
- `CHANGE_EMAIL`: بالشكل `username:new_email`.

احذف قيمة متغير الصيانة بعد نجاح العملية حتى لا يعاد تشغيلها عند كل نشر.

## لوحة الإدارة

تظهر خانة **الإدارة** تلقائيًا بعد تسجيل الدخول بحساب موجود في `ADMIN_SET`. تتيح:

- عرض كل الحسابات والبحث بالاسم أو اسم المستخدم أو البريد.
- الاطلاع على بيانات الحساب وسجل مهامه وإحصاءاته الشهرية.
- تعديل الاسم والبريد الإلكتروني.
- إعادة تعيين كلمة مرور حساب آخر مع إنهاء جلساته القديمة.
- تسجيل خروج حساب آخر من جميع الأجهزة.
- حذف الحسابات العادية. لا يمكن حذف حساب مدير من اللوحة.

لا تعرض لوحة الإدارة كلمات المرور الحالية أو تجزئاتها.

## التشغيل المحلي

```bash
npm ci
npm run build
npm start
```

ثم افتح `http://localhost:3000`.

عند عدم وجود `DATABASE_URL` يعمل التطبيق في وضع محلي، وتبقى البيانات داخل المتصفح.

## الاختبارات

```bash
npm test
```

تغطي الاختبارات التكرار اليومي والأسبوعي والشهري والمخصص، نهايات الأشهر، فروق الأيام، نافذة الظهور، الإحصائيات، ومنع حلقات ربط المهام.

## ملاحظات الأمان

- كلمات المرور الجديدة تحفظ بتجزئة `scrypt` مع قيمة salt مستقلة.
- الحسابات القديمة التي كانت تستخدم الصيغة السابقة تُرقّى تلقائيًا عند أول تسجيل دخول ناجح.
- المتصفح يحتفظ برمز جلسة قابل للإلغاء بدل حفظ كلمة المرور.
- لا يقدّم الخادم ملفات الإعداد أو المصدر الخلفي كملفات عامة.
- لا تضع رابط قاعدة البيانات أو كلمات المرور في صور أو ملفات داخل المستودع.
