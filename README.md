# EF3L Control

لوحة إدارة مستقلة وآمنة لموقع EF3L. تتصل بقاعدة PostgreSQL نفسها من الخادم فقط، ولا ترسل بيانات الاتصال إلى المتصفح.

## الوظائف

- إحصاءات قاعدة البيانات والسعة التقديرية المتبقية.
- قائمة الحسابات والبحث والتصفح على دفعات.
- تفاصيل كل حساب وحجمه ومهامه وسجلاته وإعداداته.
- تعديل الاسم والبريد وإعادة تعيين كلمة المرور.
- إغلاق جلسات المستخدم وحذف الحسابات غير المحمية.
- حذف مهمة أو سجل منفرد مع حفظ أثر الحذف.
- تصدير نسخة JSON آمنة من الحساب.
- سجل تدقيق مستقل لكل إجراء إداري.

## التشغيل

```bash
npm ci
npm run build
npm start
```

انسخ `.env.example` إلى `.env` محليًا عند الحاجة. لا ترفع ملف `.env` أو `node_modules`.
